# CAPS 기획부

코딩 동아리 CAPS 기획부가 회의록과 일정을 함께 관리하는 웹앱입니다.

Supabase로 데이터를 저장하고 Google 로그인으로 멤버를 확인합니다. 동시 편집과 캡처 기능은 개발 중입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 확인

```bash
npm test
npm run lint
```

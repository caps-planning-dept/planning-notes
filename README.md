# CAPS 기획부

코딩 동아리 CAPS 기획부가 회의록과 일정을 함께 관리하는 웹앱입니다.

현재는 화면과 동작을 먼저 만든 단계이며, 내용은 사용하는 브라우저에만 저장됩니다. 로그인과 동시 편집은 다음 단계에서 연결합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

## 확인

```bash
npm test
npm run lint
```

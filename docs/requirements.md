# CAPS 기획부 앱 요구사항

코딩 동아리 CAPS 기획부가 회의록과 일정을 함께 관리하는 웹앱입니다. 기획부 7명으로 시작하고, 필요하면 동아리 전체(40명 미만)로 확장합니다.

결정 이유는 [의사결정 기록](portfolio/decisions.md)을 참고합니다.

## 첫 버전 기능

### 로그인과 권한

- Google 계정으로 로그인하고, 초대받은 사람만 가입할 수 있음
- 로그인하지 않으면 아무 내용도 볼 수 없음
- `관리자`: 멤버 초대와 내보내기, 그 외 모든 기능
- `멤버`: 모든 탭 보기와 수정

### 탭

- 사이드바에서 탭을 만들고, 탭 안에 하위 탭을 만듦
- 탭을 만들 때 `일반 노트` 또는 `달력` 템플릿 선택
- 페이지 안의 탭 막대에서 탭을 여러 세부 탭으로 나누고 전환함. 세부 탭은 사이드바의 하위 탭과 같으며, 노트와 달력을 섞을 수 있음
- 삭제한 탭은 휴지통에 30일간 보관하고 복구할 수 있음
- 탭마다 색상을 추천 색상이나 직접 선택한 색으로 지정
- 사이드바의 최상위 탭은 최근에 만든 탭이 맨 위에 옴. 하위 탭과 탭 나누기로 만든 세부 탭은 먼저 만든 탭이 위에 옴
- 최상위 탭을 고정하면 모든 멤버의 사이드바에서 맨 위에 옴. 고정한 탭끼리는 최근에 고정한 탭이 위에 옴
- 탭 머리의 `탭 위치 옮기기` 버튼으로 하위 탭을 최상위로 올리거나, 최상위 탭을 다른 탭 안으로 넣음. 하위 탭도 함께 옮겨지고, 자기 하위 탭 안으로는 옮길 수 없음. 하위 탭이 되면 고정이 풀림

### 일반 노트

- 여러 명이 동시에 수정하고, 변경 내용과 커서 위치가 바로 보임
- 글자 서식: 글꼴(기본, 명조, 제목용), 글씨 색, 굵게, 기울임, 밑줄, 형광펜
- 글을 선택하면 `답글` 버튼이 뜨고, 답글을 남기면 넓은 화면에서는 본문 오른쪽에, 좁은 화면에서는 글 근처에 표시됨. 답글에 파일을 첨부하는 기능은 넣지 않음
- 글자를 골라 `다른 탭 연결`을 누르면 그 글자를 눌러 다른 탭으로 이동함. 글자를 고르지 않았으면 탭 이름이 연결된 채로 들어감
- 사진은 노트 안에 바로 보이고, 다른 파일은 이름과 크기가 보이는 칸으로 들어가 눌러서 내려받음. 버튼, 붙여넣기, 끌어다 놓기로 올림. 한 파일 최대 10MB

### 이름 설정

- 멤버가 사이드바에서 자기 이름을 바꿈 (최대 50자). 멤버 목록, 함께 편집, 답글에 표시됨

### 문의

- 멤버가 기능 추가 요청을 제목과 내용으로 남김
- 작성자와 관리자만 볼 수 있고, 관리자가 `접수`와 `완료` 상태를 바꿈

### 달력

- 월간 보기
- 날짜별 일정 입력: 제목, 시작·종료 날짜, 시간(선택), 담당자, 메모, 색상, 회의록 탭 연결
- 여러 날에 걸친 일정은 끊기지 않는 막대로 표시하고, 주가 바뀌면 다음 줄에서 이어짐
- 회의록 탭이 연결된 일정을 누르면 그 탭으로 이동하고, 수정은 일정의 연필 버튼으로 함
- 연결이 없거나 연결된 탭이 휴지통에 있는 일정을 누르면 수정 창이 열림
- 일정 변경이 다른 멤버 화면에 바로 반영됨

### 멤버 목록

- `최근 로그인`, `현재 접속 중`, `최근 활동` 표시

## 캡처 기능

캡처는 기획부가 진행하는 친목 활동입니다. 현재 진행 방식은 다음과 같습니다.

1. 구글폼으로 원하는 날짜와 활동을 신청받는다.
2. 응답을 스프레드시트에서 확인한다.
3. 기획부가 날짜별로 나누고, 그 안에서 활동별로 팀을 구성한다.
4. 날짜별 조를 표로 만들어 공지한다.

원하는 기능은 다음과 같습니다.

- 스프레드시트를 업로드한다.
- 날짜와 활동을 중복 선택해 신청자 이름을 분류해서 본다.
- 이름을 누르면 학번, 신청 시간 등 상세 정보를 본다.

확정한 방식은 다음과 같습니다.

- **위치:** 회차마다 `캡처` 템플릿 탭을 하나씩 만든다.
- **신청:** 파일 업로드 대신 앱 전용 신청 폼으로 받고, 날짜와 활동 목록은 회차마다 기획부가 설정한다. 기타 활동은 필터에서 `기타`로 묶는다.
- **신청자 확인:** 로그인 없이 신청한다. 같은 사람의 중복 신청을 허용하고, 신청마다 따로 기록한다.
- **공개 폼 보호:** 신청 폼은 회차별 링크와 마감 시간을 두고, 내용 저장만 할 수 있으며 신청 내용은 볼 수 없다. 자동 등록 방지 장치(사람에게 보이지 않는 입력칸, 회차당 분당 60건 제한)와 개인정보 이용 안내를 둔다. 별도의 동의 체크는 받지 않는다.
- **중복 신청 표시:** 날짜 추가 등을 위해 다시 신청할 수 있으므로, 같은 학번의 신청을 한 사람으로 묶어 보여 주고 신청별 내용과 시간은 상세 보기에서 확인한다. 나중 신청은 앞 신청에 더해지며, 필터에는 그 사람의 모든 신청에 있는 날짜와 활동을 합쳐서 적용한다.
- **필터:** 날짜끼리와 활동끼리는 하나라도 해당하면 표시하고, 날짜와 활동 사이는 둘 다 해당해야 표시한다.
- **신청 현황:** 요약 수치, 날짜별·활동별 인원, 신청자 명단으로 현황만 보여 준다.
- **조 편성:** 필터로 신청자를 좁히고 이름을 눌러 고른 뒤, 날짜와 활동을 정해 `조 편성하기`로 조를 만든다. 고른 사람을 기존 조에 넣을 수도 있다.
- **열람 권한:** 캡처 탭마다 관리자가 볼 사람을 지정한다.
- **조 번호:** 앞 날짜일수록 앞번호, 같은 날짜는 만든 순서대로 매기며 회차 전체에서 겹치지 않는다.
- **조장:** 조마다 한 명을 두고, 처음 고른 사람이 기본 조장이 되며 바꿀 수 있다. 표의 맨 위 줄에 다른 색으로 표시한다.
- **공유 표:** 날짜별로 조를 열로 나란히 배치해 이미지로 저장한다. 이미지에는 날짜, 활동, 조, 메모, 이름만 넣는다.
- **개발 순서:** Supabase와 로그인, 캡처 탭과 신청 폼, 필터와 상세 보기, 조 편성 표와 이미지 저장 순서로 만든다.

기존 구글폼의 항목은 다음과 같습니다.

| 항목 | 입력 방식 |
|---|---|
| 타임스탬프 | 자동 기록 |
| 이름, 학번 | 직접 입력 |
| 기수 | 직접 입력 (예: 40.5기) |
| 전공 | 직접 입력 |
| 함께 조를 하고 싶은 사람 | 직접 입력, 선택 사항 |
| 참여 희망 날짜 | 복수 선택 |
| 희망 참여 횟수 | 단일 선택: 1회, 2회, 3회 이상 |
| 음주 여부 | 단일 선택: 음주, 비음주, 상관없음 |
| 추가로 하고 싶은 활동 | 복수 선택과 기타 입력, 선택 사항 |

기존 양식에서 확인한 문제는 다음과 같습니다.

- 활동 이름 안에 쉼표가 있어(예: `축제 (9/29, 9/30, 10/1)`) 쉼표만으로 나누면 항목이 잘못 나뉜다.
- 전공을 직접 입력해 같은 전공도 표기가 제각각이다.
- 기타 입력에는 활동 이름이 아닌 자유 문장이 섞인다.

실제 신청자 정보는 저장소와 문서에 넣지 않습니다.

## 운영 원칙

- Google 로그인은 배포 전까지 테스트 모드로 운영하고 테스트 사용자를 등록. 배포 후 홈페이지와 개인정보처리방침 주소를 입력해 앱을 게시
- 월 0원으로 시작하고, 한도에 도달하면 유료 전환을 다시 논의
- 매일 자동 백업 (회의록 답글은 Liveblocks에 저장되므로 백업 범위에 따로 포함해야 함)
- 비밀 키, 노션 내보내기 파일, 회의록 백업은 공개 저장소에 넣지 않음
- 서비스 계정은 담당자 개인 계정으로 운영하고, 소유권 이전 절차를 인수인계 문서에 포함

## 세부 규칙

### 탭 색상

- 추천 색 12개와 자유 색상 선택기 제공
- 사이드바 표시, 탭 제목 강조, 탭 안의 버튼과 선택 표시에 적용하고, 본문 글자에는 적용하지 않음
- 탭 색 위의 글자는 흰색을 우선하고, 흰 글자가 잘 보이지 않는 밝은 색에서만 검은색을 씀
- 색은 탭에 저장되어 모든 멤버에게 똑같이 보임
- 색을 정하지 않은 하위 탭은 상위 탭의 색을 따름
- 일정은 기본으로 탭 색을 쓰고, 일정별로 다른 색도 고를 수 있음

### 초대

- `관리자`가 7일 뒤 만료되는 초대 링크를 만들고, 멤버 화면의 유효한 링크 목록에서 언제든 취소할 수 있음
- `관리자`는 멤버를 내보낼 수 있음
- 처음 관리자는 개발 담당자

### 백업

- 동아리 Organization의 별도 비공개 저장소에 매일 보관

### 카카오톡 내부 브라우저

- 감지되면 외부 브라우저로 열도록 안내하고 링크 복사 버튼 제공

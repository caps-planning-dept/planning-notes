## 주의할 점
- 사용자는 비전문가다. 용어를 쉽게 풀고 콘솔 작업은 한 화면씩 안내한다. 스크린샷을 받아 확인하는 방식이 잘 통했다.
- Supabase MCP는 새 세션부터 읽기 전용이다. DB 구조를 바꿔야 하면 `.mcp.json`의 `read_only=true`를 잠시 빼거나, 마이그레이션 내용을 보여 주고 승인받은 뒤 진행한다.
- 권한·복구 시험은 `do` 블록 끝에서 일부러 `raise exception`으로 결과를 내고 모두 취소하는 방식이 확실하다.
- 되돌릴 수 없는 삭제(휴지통 비우기, 영구 삭제, 일정과 문의 삭제)는 대신 실행하지 않는다.
- 개인정보는 개수로만 조회한다. 비밀 키는 채팅으로 받지 않는다. 공개 저장소라 실제 이름, 학번, 토큰을 문서와 커밋에 넣지 않는다. 내려받은 백업 파일은 저장소에 넣지 않는다.
- 초대 링크는 7일 동안 여러 번 쓸 수 있다. 쓰고 나면 멤버 화면에서 취소한다.
- 앱 안 브라우저 창은 내보낸 두 번째 계정으로 로그인돼 있어 `초대가 필요합니다`만 보인다. 관리자 화면은 사용자 Chrome에서 확인한다.
- Liveblocks 운영 키를 Roll하면 앱이 끊긴다. Roll하면 Vercel과 백업 저장소를 함께 바꾸고 재배포한다.
- 승인된 도메인의 supabase 항목을 지우면 로그인이 깨질 수 있다. 브랜딩에 로고를 올리면 검토가 시작될 수 있다 (추측).
- 시험하지 않은 것: 좁은 화면의 휴지통 버튼, 테스트 사용자 목록에 없던 계정의 로그인, 휴지통 30일 자동 삭제, CSP, 복구 시 노트 화면에 DB 내용이 보이는지(Liveblocks 방이 남아 있으면 방 내용이 보일 것으로 추측), 답글 복구
- 영구 삭제나 30일 자동 삭제를 해도 Liveblocks 방과 백업(30일)에는 내용이 남는다.
- 남은 틈: 멤버가 자기 탭의 상위 탭이나 일정 연결 탭을 숨은 캡처 탭으로 지정 가능 (탭 번호를 알아야 함, 막지 않음)

## 주의할 점
- 사용자는 비전문가다. 용어를 쉽게 풀고 콘솔 작업은 한 화면씩 안내한다.
- DB를 바꾸는 SQL은 내용을 먼저 보여 주고 승인받는다. 지금 Supabase MCP는 실제 DB에 쓸 수 있다.
- 되돌릴 수 없는 삭제(휴지통 비우기, 일정과 문의 삭제)는 대신 실행하지 않고 사용자에게 맡긴다.
- 개인정보는 개수로만 조회한다. 신청 화면의 글자를 통째로 읽지 않는다. 비밀 키는 채팅으로 받지 않는다.
- 공개 저장소다. 실제 이름, 학번, 토큰을 문서와 커밋에 넣지 않는다. 연락처 이메일만 `/privacy`에 공개한다.
- Liveblocks 운영 키를 Roll하면 앱이 끊긴다. Roll하면 Vercel과 백업 저장소를 함께 바꾸고 재배포한다.
- 기존 답글 2개는 개발용 Liveblocks에만 있다. 시험 데이터라 옮기지 않았다.
- 시험하지 않은 것: 휴지통 30일 자동 삭제, 캡처 탭 복원 시 폼 상태, 내보낸 뒤 Liveblocks 권한 유효 시간, 탭 삭제 시 첫 화면 이동
- `.mcp.json`, `AGENTS.md`, 이 메모는 공개하기로 결정했다.

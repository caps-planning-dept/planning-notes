## 주의할 점
- 사용자는 비전문가다. 용어를 쉽게 풀고 콘솔 작업은 한 화면씩 안내한다.
- DB를 바꾸는 SQL은 내용을 먼저 보여 주고 승인받는다. 지금 Supabase MCP는 실제 DB에 쓸 수 있다. 권한 시험은 `begin; set local role authenticated; ... rollback;` 방식이 동작함
- 되돌릴 수 없는 삭제(휴지통 비우기, 일정과 문의 삭제)는 대신 실행하지 않는다. 단 Claude가 만든 시험 데이터는 앱 화면에서 정리했다.
- 개인정보는 개수로만 조회한다. 비밀 키는 채팅으로 받지 않는다. 공개 저장소라 실제 이름, 학번, 토큰을 문서와 커밋에 넣지 않는다.
- Liveblocks 운영 키를 Roll하면 앱이 끊긴다. Roll하면 Vercel과 백업 저장소를 함께 바꾸고 재배포한다.
- 앱 안 브라우저 창에는 배포 주소 로그인 정보가 없다 (로그인 없는 시험에 사용)
- 남은 틈: 멤버가 자기 탭의 상위 탭이나 일정 연결 탭을 숨은 캡처 탭으로 지정 가능 (탭 번호를 알아야 함, 막지 않음)
- 탭을 휴지통으로 옮기면 첫 화면이 아니라 다음 탭이 열림. 의도 여부 미정
- 시험하지 않은 것: 휴지통 30일 자동 삭제, 캡처 탭 복원 시 폼 상태, 내보낸 뒤 Liveblocks 권한 유효 시간, CSP
- 기존 답글 2개는 개발용 Liveblocks에만 있다. 시험 데이터라 옮기지 않았다.

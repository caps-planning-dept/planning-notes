## 주의할 점
- 사용자는 비전문가다. 용어를 쉽게 풀고 콘솔 작업은 한 화면씩 안내한다.
- Supabase MCP는 지우는 SQL(열·정책·함수 삭제)을 확인 창 없이 거절했다(3번). 더하기만 하는 SQL은 적용됨. 지우는 변경은 사용자가 SQL 편집기에서 실행해야 할 수 있다(추측).
- 시험한 실제 시간표 사진은 개인 자료라 저장소에 넣지 않는다. 자동 테스트는 그린 그림으로 한다.
- Gemini 무료 사용분은 Google이 서비스 개선에 쓸 수 있다. 앱은 사진을 저장하지 않는다.
- 되돌릴 수 없는 삭제는 대신 실행하지 않는다. 개인정보는 개수로만 조회한다.
- 화면 시험은 사용자 Chrome에서 한다. 로컬도 같은 실제 DB를 쓰므로 시험 데이터는 시험 뒤 지운다.
- 시험하지 않은 것: 실제 사이트의 사진 읽기, 실제 카카오톡 복사, 휴대폰 화면·붙여넣기 칸, 일반 멤버 권한으로 시간표 고치기, 표의 칸 너비 끌기
- 개발 중 노트를 열면 Next.js 화면에 `flushSync` 경고가 뜬다. 편집기 사진 칸 때문이고 동작에는 영향 없음

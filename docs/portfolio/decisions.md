# 의사결정 기록

포트폴리오와 인수인계에 쓰기 위해, 프로젝트의 주요 결정과 이유를 남기는 문서입니다.
비용과 한도는 확인한 날짜 기준이며 바뀔 수 있습니다.

## 프로젝트 조건 (2026-11-05)

- **사용자:** 기획부 7명으로 시작하고, 확장해도 40명 미만
- **예산:** 월 0원으로 시작
- **접근 권한:** 로그인한 멤버만 볼 수 있음 (`관리자`, `멤버` 두 단계)

## 첫 버전 범위

1. Google 로그인과 초대
2. 사이드바의 탭 목록, 탭 생성, 하위 탭, 30일 휴지통
3. 동시 편집되는 일반 노트
4. 날짜별로 일정을 입력하는 월간 달력
5. 멤버 목록의 최근 로그인, 현재 접속 여부

다음 버전으로 미룬 기능: 댓글, 알림, 파일 첨부, 회의록 템플릿, 내용 버전 복원, 반복 일정, Google 캘린더 연동
